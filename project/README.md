# AE-Simulator · `project/` — дзеркало робочого столу

живе доки: робота над AE ведеться в чатах Claude із Project-контекстом

**Що це.** Тека `project/` у репо — **дім** усього, що раніше лежало тільки в claude.ai Project
і гинуло при міграції акаунтів. Репо старше за Project: Project — читалка на старті сесії,
`project/` — сховище. Розбіжність між ними = подія, яку розбирають до роботи.

## Карта

| тека | що лежить | хто читає |
|---|---|---|
| `summary/` | ЧЕРГА (відкрите по продукту) · **живе** самері сесії | Claude на старті кожної сесії — цілком |
| `knowledge/` | SPEC · бібліотека характерів · MOOD · спека судді · досьє композера | точково, коли задача торкається |
| `stand/<предмет>/` | живі стенди: шаблон · генератор · скрипт проходу · файл знахідок | Claude у ході роботи над цим предметом |
| `stand/sources/` | джерела A-екранів: макети й сайдбар, з яких знімається розмітка | при порті екрана в продукт |
| `tools/` | робочі скрипти поза рантаймом продукту (прев'ю, збірники) | за потреби |
| `_MANIFEST.md` | ім'я · md5(8) · «живе доки» · щабель черги | звірка на старті |

## Межі

- Рантайм продукту — `tools/ae_rules.js`, `worker/`, `data/`, `prompts/`, `index.html` у корені репо.
  `project/` продукт **не їсть**: це робоче знання й стенди.
- `index_work/` — **заплановане сховище** страхової копії робочого `AE_WORK_index_X*.html`
  (В-115 · S79): сховище, не рантайм. Продукт звідти нічого не читатиме; опублікований для Олі
  білд лишається `index.html` у корені. Теки ще немає: скрипт ядра `Lens_claude_github_push.py`
  блокує такий шлях (`FORBIDDEN_PATH`, В-31/В-94) — знімається правкою ядра в governance-сесії.
- Зібраний мокап (`AE_MOCK_*.html`) сюди **не кладеться**: він детерміновано відтворюється
  з `шаблон + генератор` (П34 · П37). Зберігати похідне — зберігати те, що й так рахується.
- Мертві версії стендів ідуть у `archive/stand/`, одноразові `vNN_apply` — у `archive/apply/`.

## Як оновлюється

Хід, що видав нову версію файла стенда, закінчується пушем сюди; попередня версія тим самим
комітом іде в `archive/`; `_MANIFEST.md` оновлюється тим самим комітом (П118).
