# Аптека АНЦ — Brand Color Tokens (2026)

**Документ для агентів / UI-розробників**  
Версія: 1.0  
Дата збору: 2026-09-11  
Джерела: офіційний сайт [anc.ua](https://anc.ua), SVG-логотип, CSS-стилі сайту, вивіски аптек, мобільний застосунок.

---

## 1. Призначення документа

Цей файл містить **офіційні (фактично використовувані) кольорові токени** мережі аптек **АНЦ** (Аптека Низьких Цін / ANC) станом на 2026 рік.

Мета:
- Дати чітку, готову до копіювання палітру для перенесення тематики АНЦ у свій застосунок / сайт / симулятор.
- Служити **single source of truth** для AI-агентів, дизайнерів і розробників, які працюють з візуальною ідентичністю АНЦ.
- Уникнути при створенні UI-тем, CSS-змінних, дизайн-систем і mockup-ів.

> **Важливо:** Публічного офіційного брендбука з Pantone/HEX від компанії не знайдено. Токени витягнуті з живого продакшену (логотип SVG, header-градієнт, CSS сайту anc.ua). Кольори стабільні і не змінювалися суттєво після ребрендингу «Турбота».

## 2. Основна палітра (Primary)

| Токен | HEX | RGB | Опис / Використання |
|-------|-----|-----|---------------------|
| `--anc-yellow` | `#FFDF01` | `rgb(255, 223, 1)` | Основний жовтий. Фон логотипу, вивіски, великі акценти, header. |
| `--anc-yellow-dark` | `#FFC939` | `rgb(255, 201, 57)` | Темніший жовтий. Кінець градієнта шапки. |
| `--anc-blue` | `#008FCC` | `rgb(0, 143, 204)` | Основний синій. Літери «АНЦ» у логотипі, іконки, primary-кнопки, посилання. |
| `--anc-blue-alt` | `#008AD2` | `rgb(0, 138, 210)` | Альтернативний синій (часто зустрічається в CSS). |

### Градієнт шапки (як на anc.ua)

```css
--anc-header-gradient: linear-gradient(180deg, #FFDF01 27.02%, #FFC939 83.32%);
```

## 4. Готовий CSS-блок (копіюй і використовуй)

```css
:root {
  /* === ANC Brand Primary === */
  --anc-yellow: #FFDF01;
  --anc-yellow-dark: #FFC939;
  --anc-blue: #008FCC;
  --anc-blue-alt: #008AD2;

  /* Gradient (header style) */
  --anc-header-gradient: linear-gradient(180deg, #FFDF01 27.02%, #FFC939 83.32%);

  /* === Neutrals === */
  --anc-white: #FFFFFF;
  --anc-text: #1C1E24;
  --anc-text-dark: #212121;
  --anc-gray: #6E6E77;
  --anc-gray-light: #9B9CA1;
  --anc-border: #E7E7E7;
  --anc-bg-light: #FFFAD6;
  --anc-bg-soft: #FEFFE7;

  /* === Semantic === */
  --anc-success: #27AA7B;
  --anc-success-dark: #1E815D;
}
```

### Рекомендовані правила використання

- **Header / логотип / великі CTA** → `--anc-yellow` + градієнт + текст/іконки `--anc-blue`
- **Primary-кнопки** → фон `--anc-blue`, текст білий
- **Фон сторінки** → `--anc-white`
- **Картки / підсвітки** → `--anc-bg-light` або `--anc-bg-soft`
- **Текст** → `--anc-text`
- **Успішні статуси / бейджі** → `--anc-success`

## 5. Пояснення для AI-агента

**Контекст:**  
Мережа «Аптека АНЦ» — одна з найбільших аптечних мереж України. Візуальна ідентичність побудована на контрасті яскравого жовтого (енергія, вигода, «низькі ціни») і спокійного синього (довіра, турбота, медицина). Після ребрендингу (агентство DSTRCT) акцент зроблено на архетип «Турботливий» — закруглені форми, м’які лінії, персонажі в cartoon-стилі.

**Як агент має використовувати цей документ:**

1. При генерації UI / mockup / CSS / Tailwind-конфігу — **обов’язково** брати кольори з цього файлу.
2. Не вигадувати «схожі» жовті/сині. Використовувати точні HEX.
3. Градієнт шапки — канонічний (з живого сайту).
4. Логотип: жовтий фон + синій текст «АНЦ» + синій елемент рук/кола.
5. При створенні темної теми — зберігати жовтий і синій як акценти, фон робити темним нейтральним.
6. Документ можна цитувати як `docs/ANC_Brand_Color_Tokens_2026.md`.

**Обмеження:**  
Токени зібрані з відкритих джерел (сайт + SVG). Якщо з’явиться офіційний брендбук від «Аптека-Магнолія» / АНЦ — цей файл потрібно оновити.
