## §0 ВІДКРИТЕ — читати першим

1. **⚠ в-1 не закритий одним рядком.** Воркер `ae-edit` розгорнутий і
   відповідає (`https://ae-edit.konstandre.workers.dev/`). Пряме відкриття в
   браузері дало `403 · «Запит прийшов не з дозволеного домену»` — це **норма**:
   навігація не шле `Origin`. Але **чи вклались правила у бойову збірку —
   не перевірено**, бо `GET` стоїть за охороною. Закриває один прогін:
   ```
   curl.exe -s -H "Origin: https://konst-andre.github.io" https://ae-edit.konstandre.workers.dev/
   ```
   Чекаємо `{"ok":true,"step":"в-1","rules":"живі","writes":false}`.
   `"rules":"НЕ ЗІБРАЛИСЬ"` = інтероп зламався на бойовій збірці (у контейнері
   був зелений). `500` про `AE_EDIT_CODE` = секрет не долетів.
   **Поки цей рядок не зелений — у в-2 не заходити.**

2. **⚠ Дата смерті токена Cloudflare не записана.** Оператора спитано, відповіді
   не було. Токен із терміном помирає мовчки, і редактор виглядатиме зламаним.
   Спитати першим ділом; якщо термін не ставився — записати «без терміну».

3. **Три дефекти пояснення панелі перевірки — досі не закриті**, переїхали з
   `S9 §0.2` без змін. Їдуть хвостом із наступною правкою `index.html`
   (тобто з в-3, бо в-1/в-2 `index.html` не чіпають):
   - **«Дані застосунку» мовчить** — або говорить, або неактивна, доки файл не вибрано;
   - **рядок «Судиться: …» звітує про порожнечу** — у порожньому стані `display:none`;
     формулювання вибраного стану: «Замість даних застосунку судиться файл: `імʼя` (каталог)»,
     два файли через `·`. Слова «дані застосунку» як **імені боку** більше немає;
   - **вступний абзац бреше** — новий текст: «Прогін тих самих правил, що ганяються
     на кожен push у репозиторій. За замовчуванням судяться дані самого застосунку;
     можна підставити файл із телефона. Нічого не змінює.»

4. **`S9 §0.1` закрито — дефекту немає.** Device-прогін дав
   «Судиться: каталог — `catalog.json` · сценарії — дані застосунку», тобто
   спрацювала перша гіпотеза: попередній знімок був знятий після скидання.
   `classifyJson` форму впізнає.

5. **Тост знято з предмета свідомо.** Рішення оператора після розбору: тост —
   носій події, а «що зараз судиться» — стан; зниклий тост лишає список
   вердиктів без підпису. Повертаємось до нього **тільки** якщо після правки
   §0.3 поява/зникнення рядка все одно пройде повз око на пристрої.

6. **`AE_ORIGINS` в `ae-edit` покладено як Secret, а не Plain text** — навмисно,
   див. §2.3. У `ae-proxy` воно лишається Plain text і це вірно: той воркер
   вставляється руками й wrangler ним не керує.

7. **Ручне зобовʼязання:** `build` у `config.json`. Поточне — `v13 · 3 вересня 2026`.
   Крок в-1 `index.html` не чіпав, тож число не мінялось.

## §1 Що зроблено

**Вибрано четвертий вихід (Г): воркер збирається, а не вставляється.**
Розвилка «як вкласти правила у воркер» розібрана заново після того, як
оператор зняв обмеження «ПК немає» (§2.1). Три попередні виходи відкинуті:

| | вирок |
|---|---|
| (А) перевести все на ESM | радіус 6 файлів, MIME `.mjs` на Pages неперевірений |
| (Б) воркер не судить | звужує межу `S9 §4` заради економії, яка стала непотрібною |
| (В) вбудована копія + гейт тотожності | **рекомендація знята автором.** Гейт тотожності — сторож при копії; збирач копії не створює |
| **(Г) збірка wrangler + деплой із CI** | ✓ одне тіло правил, нуль змін у `ae_rules.js` / `index.html` / смоуках, деплой із телефона |

**Чотири нові файли, жоден наявний не чіпався:**

| файл | роль |
|---|---|
| `worker/ae-edit.js` | воркер редактора. **Тільки судить, нічого не пише** |
| `wrangler.toml` | опис воркера `ae-edit` для збирача |
| `.github/workflows/deploy-edit.yml` | суха збірка → гейт → деплой на push |
| `tools/smoke_edit_v1.mjs` | гейт: ганяє **зібраного** воркера на справжніх даних |

**Рішення, ухвалені в коді:**
- **дефолтний імпорт, не іменований** — `import rules from '../tools/ae_rules.js'`.
  Іменований імпорт із CommonJS тримається на здогадці збирача про форму
  експорту; дефолтний віддає `module.exports` цілим;
- **`AE_EDIT_CODE` окремий від `AE_CODE`** — право говорити з моделлю ≠ право
  правити дані;
- **без секрета воркер червоніє, а не пускає** — `500 · «Редактор не
  налаштований»`. Мовчазний дозвіл виглядав би як робота і був би дірою;
- **код їде заголовком у `encodeURIComponent`** — кирилиця в заголовку HTTP
  інакше падає на `non ISO-8859-1 code point` (вже наступали в `ae-proxy`);
- **обидва боки судяться разом** — правила звіряють сценарії з каталогом,
  бік, якого не надіслали, підставити нізвідки: воркер стану не тримає;
- **суха збірка ПЕРЕД деплоєм** (`wrangler deploy --dry-run`) — токена не
  потребує, ловить зламаний інтероп до того, як зламаний воркер поїде в бій.

**Розслідування замість здогадок** (на прохання оператора «краще 10 разів
заміряти»). Три пошуки в мережі + справжня збірка esbuild у контейнері.
Підтверджено джерелами: `cloudflare/wrangler-action@v4` розгортає воркер із
GitHub Actions за секретами `CLOUDFLARE_API_TOKEN` / `CLOUDFLARE_ACCOUNT_ID`;
GitHub REST вимагає валідний `User-Agent`, інакше `403` (важливо для в-2);
`PUT /contents` хоче `message`, base64-`content` і **обовʼязковий `sha`** при
оновленні наявного файлу.

## §2 Правила, що народились у сесії — повним текстом

**2.1 · «ПК немає» — це замовчування, а не константа.**
ДІМ: `kernel/wsd/Work_Standard.md`, `1.14`, доповненням. **Не влито.**

Коли форма кроку залежить від наявності командного рядка (деплой, збірка,
встановлення інструментів, разове налаштування токенів), асистент **питає** на
початку кроку: оператор зараз у полі чи за компʼютером. Питання ставиться так
само, як питання про пристрій тесту в бенчі — **до** вибору форми, не після.
Не спитати — значить обрати найдорожчий із можливих шляхів і назвати це
обмеженням.

⚠ Прецедент цієї сесії: три виходи були побудовані як відповідь на «ПК немає»,
і всі три виявились гіршими за четвертий, який ПК на разове налаштування
використовує. Ціна непоставленого питання — цілий раунд планування.

**2.2 · Гейт перевіряє артефакт, який поїде в продакшн, а не джерело.**
ДІМ: `kernel/wsd/Work_Standard.md`, `12.12`, доповненням. **Не влито.**

Зелене джерело нічого не каже про зібране: перетворення між ними має власні
правила, і саме там ховаються поломки, невидимі у вихідному файлі. Гейт
ганяє те, що поїде: бандл, а не модуль; згенерований HTML, а не шаблон;
експортований файл, а не таблицю, з якої він робиться.

⚠ Доказ цієї сесії, спійманий прогоном, а не роздумами: перша версія гейта
шукала в бандлі український рядок і **впала на цілій збірці** — збирач екранує
не-ASCII у `\uXXXX`. Пішло б у CI як є — червоне на робочому коді. Якір
замінено на ASCII (`AE_RULES`).

⚠ Ширина правила: воно накриває не лише бандлери. `KPI Lens` — той самий
випадок: гейт має ганяти згенерований HTML, а не шаблон, з якого він
збирається.

**2.3 · Воркером керує один хазяїн: або дашборд, або конфіг.**
ДІМ: коментар у `wrangler.toml` (частково є) + це самері. **Не влито повністю.**

Для воркера, розгорнутого з репо, звичайні змінні (`vars`) належать
`wrangler.toml`: змінна, додана в дашборді й відсутня в конфізі, може зникнути
на наступному деплої. Секрети wrangler не чіпає — вони живуть окремо і
переживають деплої. Тому в `ae-edit` **обидві** змінні кладуться як Secret.
Дзеркально: воркер, який вставляється руками (`ae-proxy`), у `wrangler.toml`
описувати НЕ можна — наступний деплой затре дашбордну версію.

## §4 План

**в-1** (закривається `curl` із §0.1) → **в-2 · запис** → **в-3 · форма для Олі**
→ **Ж-4** → **М** (міграція на акаунти Олі) → **З** → **Д** (панель моделей)
→ **Г**. Порядок ухвалений оператором у S7 і не мінявся.

**в-2 · межа.** Додати до `ae-edit` токен GitHub і коміт через Contents API.
Ризик токена ізольований від ризику збірки навмисно — саме тому в-1 не писав.
Що вже відомо і не треба перевідкривати:
- `Authorization: Bearer <PAT>` + **обовʼязковий `User-Agent`**, інакше `403`,
  який читається як «токен поганий»;
- `GET /contents/<шлях>` → взяти `sha` → `PUT` із `message`, base64-`content`, `sha`;
- **`btoa` тут впаде.** Український текст у base64 — тільки через `TextEncoder`
  → байти → base64. Це той самий шрам, що й кирилиця в заголовку;
- `409` на розбіжності `sha` → людський рядок «файл змінився, відкрийте заново»;
- токен: fine-grained PAT, **один** репозиторій, `Contents: Read and write`.
  Класичний `repo`-токен не брати — він дає доступ до всіх репозиторіїв.

**в-3 · межа.** Форма для Олі: вона бачить сценарій людськими словами, не JSON.
⚠ Відкрите рішення, назване й не ухвалене: **коміт → перезбірка Pages ≈ хвилина**.
«Зберегла — нічого не змінилось» для Олі гірше за помилку. Варіант, який треба
зважити в в-3: після успішного коміту застосунок одразу тримає правлені дані
живими у себе, а репо наздоганяє.
