## §1 РІШЕННЯ СЕСІЇ

### 1.1 · Origin знято з `ae-edit`, лишено в `ae-proxy`
**Дім: коментар у шапці `worker/ae-edit.js` + цей файл. У `wsd` НЕ ллється** —
рішення пояснює конкретний воркер, а не змінює те, як ми працюємо.

`ae-edit`: під Origin стоїть `AE_EDIT_CODE`, тобто справжня охорона. Origin
підставляється руками в один рядок `curl` — проти будь-кого зі скриптом він
нічого не варт. Єдиний клас атак, від якого він рятує (чужа сторінка на куки
жертви), закритий конструкцією: куків немає, ключ їде заголовком.
Ціна ж реальна — **відмовляє мовчки**.

`ae-proxy`: `AE_CODE` знято свідомо, тож під Origin **порожнеча**. Він єдине,
що стоїть між публічним URL воркера (видно у `index.html`) і квотою Groq.
Лишається. Різна опора під перевіркою — різне рішення.

### 1.2 · Причина смерті `AE_ORIGINS` — підтверджена емпірично
Змінна лежала **Plain text**, і її змело деплоєм з CI: звичайні змінні (vars)
належать `wrangler.toml`, і те, що додане в дашборді й відсутнє в конфізі,
деплой стирає. Секрети (Encrypt) wrangler не чіпає.
Доказ: після зняття Origin `GET` дав `200`, а не `500` — отже `AE_EDIT_CODE`,
покладений як Encrypt, пережив усі шість деплоїв, а `AE_ORIGINS` помер сам.

**Дім: коментар у `wrangler.toml` + цей файл.**
Практичний наслідок: **будь-який секрет `ae-edit` кладеться тільки Encrypt.**

### 1.3 · Білий список шляхів — межа безпеки, не зручність
Шлях **ніколи** не приходить від клієнта. Клієнт називає бік
(`catalog` | `scenarios`), шлях розкладає воркер із `PATHS`.
Причина: приймали б шлях ззовні — той, хто знає `AE_EDIT_CODE`, переписав би
`.github/workflows/*.yml`, а це виконуваний код у CI, де лежить токен
Cloudflare. Слабкий код редактора став би повним контролем над інфраструктурою.
**Дім: коментар у `worker/ae-edit.js` + цей файл.**

### 1.4 · Плейсхолдери: воювати з власною арматурою, не з Олею
Прибрати `{{…}}` «бо ми їх самі створили» не можна: `{{no}}` — номер
замовлення, який генерується **під час гри**, коли Оля вже давно написала
текст. Його в тексті бути не може фізично.

Але висновок оператора правильний: **Оля не повинна їх бачити.** Помилка не в
тому, що плейсхолдери існують, а в тому, що ми збирались показати їй файл, у
якому вони живуть.

Ухвалений напрямок: **машинні дані виносяться з тексту промпта в окремий
службовий блок до моделі** («дані цього діалогу: номер 12345»). Тоді текст,
який пише Оля, стає чистим — без дужок. Структурні заголовки (`## with_number`)
перетворюються на **назви полів у формі**, а не рядки всередині тексту.
Перевірити по кожному плейсхолдеру окремо — задача в-2.5 §0.2.

### 1.5 · Обидва токени — без терміну
Cloudflare API token: без терміну.
GitHub `AE_GH_TOKEN`: fine-grained PAT, репозиторій `Konst-Andre/AE-Simulator`,
`Contents: Read and write` + `Metadata: Read-only`, **never expire**.
Ризик прострочення знято свідомо. Людський рядок на `401` у воркері лишається —
токен можна відкликати руками.

`AE_edit_S11_no_origin.zip` · `AE_edit_v2_WRITE.zip`

**Змінено:**

  GitHub на людські рядки, `commit()`)
- `tools/smoke_edit_v2.mjs` — новий, замінив `v1` (v1 **видалено з репо**)
- `.github/workflows/deploy-edit.yml` — гейт тепер `v2`
- `wrangler.toml` — коментар про Encrypt

**Контракт запису:**
`POST` з тілом `{catalog, scenarios, save?, note?}`.
`save` — рівно один рядок: `"catalog"` або `"scenarios"`. Без `save` — тільки суд.
Один `PUT` = один коміт = атомарно; напівстану не існує за конструкцією.
`✗` блокує запис, `⚠` пускає. Відповідь має поле `saved` (шлях або `null`).
